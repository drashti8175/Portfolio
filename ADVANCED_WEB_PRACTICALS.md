## Practical 4-5: Task Manager API

Folder: `task-manager-api`

What it covers:

- Express REST API
- CRUD routes
- Request logging middleware
- JSON content-type validation
- 404 handler
- Global error middleware
- Mongoose schema and MongoDB integration

Run:

```bash
cd task-manager-api
npm install
copy .env.example .env
npm run dev
```

Set `MONGO_URI` in `.env` before running the API.
