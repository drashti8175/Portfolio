# Drashti Patel – Portfolio

A modern showcase of my work, built with HTML, CSS, and JavaScript (Vite).  
It includes:

- **Responsive design** with a clean, premium aesthetic
- **Project cards** linking to live demos and GitHub repos
- **Contact section** with a functional email form
- Integrated CI workflow (GitHub Actions)

## Getting Started

```bash
# Clone the repo
git clone https://github.com/drashti8175/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run locally
npm run dev
```

## Build

```bash
npm run build   # produces a production‑ready `dist/` folder
```

## Deploy

The repository ships with a GitHub Actions workflow that automatically builds
and publishes the site to GitHub Pages on every push to `main`.
